# Klarence Geriz D. Cabrera  Portfolio

Personal portfolio website showcasing my work in **filmmaking, video editing, and photography**. Built with a cinematic and dreamy aesthetic, where technology meets creativity.

I'm a BS Information Technology student at Pamantasan ng Lungsod ng Valenzuela (PLV).

LIVE WEBSITE URL: https://klarencecabrera.gt.tc

## Features

- Home page with hero section, featured projects, skills overview, and an about strip
- Portfolio page with category filters (All, Filmmaking, Editing, Photography)
- Hover video previews (muted) on project cards
- Click-to-play video modal with sound and controls (close via the X button, clicking the backdrop, or pressing Esc)
- My Projects page: a curated archive of photography and film work
- About page with bio, education timeline, and creative skills
- Scroll animations as sections come into view
- Responsive layout with a hamburger menu for mobile
- Portfolio items are generated from a single list, so adding new work is quick

## Tech Stack

- PHP (shared page includes and dynamic portfolio grid)
- HTML5 and CSS3
- Vanilla JavaScript (no frameworks)
- Google Fonts: DM Serif Display and DM Sans

## Pages and Files

Cabrera.php – Home page
portfolio.php – Full portfolio with filters and video modal
myprojects.php – Photography and film archive
contact_about.php – About page
style (2).css – Main stylesheet
includes folder – Shared navigation and footer
assets folder – Images, videos, and logo

## Getting Started

1. Download or clone this project.
2. Install PHP, or use a local server such as XAMPP or Laragon.
3. Place the project folder in your server directory (for XAMPP, inside htdocs).
4. Start the server and open Cabrera.php in your browser.
